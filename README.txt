# Product Information System

Mini project PHP berdasarkan materi Pertemuan 2: PHP Fundamental & Data Structure.

## Struktur file

- products.php  -> menyimpan data produk dalam array multidimensi
- functions.php -> berisi fungsi pengolahan data
- index.php     -> presentation layer / tampilan HTML

## Konsep yang digunakan

- Associative array
- Array multidimensi
- foreach
- if
- function
- require_once
- Separation of Concerns
- Perhitungan total nilai stok
- Pengecekan stok kritis (< 3)

## Cara menjalankan

1. Simpan folder `product_information_system` di folder server lokal, misalnya `htdocs` jika menggunakan XAMPP.
2. Jalankan Apache.
3. Buka:
   http://localhost/product_information_system/index.php
